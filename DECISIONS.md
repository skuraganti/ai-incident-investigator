# Decisions, failures and corrections

- **Use genuine input plus measured lab observations.** A frozen USGS snapshot gives the sandbox a useful domain workflow. Explicit controlled causes produce aligned diagnostic evidence with known local scope. This does not manufacture production history or turn earthquake data into a production incident benchmark.
- **Two small services, no full observability cluster.** OTel Demo's documented resource needs exceed this VM. Manual correlated records demonstrate the evidence model using standard UUIDs and measured durations without claiming OpenTelemetry protocol compliance.
- **Real exceptions rather than fabricated telemetry.** SQLite's exclusive/read contention actually raises OperationalError; incompatible field access actually raises KeyError; a delayed loopback HTTP route actually exceeds an httpx read timeout. Aggregation delay is artificial sleep, but measured elapsed times are real. No fake latency/CPU/memory measurements.
- **Frozen source, no live label.** Source updates upstream; original local bytes are retained with checksum/generated/retrieval times. A missing original cannot be silently replaced by a newer feed. Separate source and service-event clocks matter.
- **Immutable case evidence.** App copies each complete6request case before sandbox retention evicts older requests. Quotes bind to a SHA256 evidence bundle and stable IDs. Existing cases are not rewritten to fix scores.
- **Cautious AI, explicit mechanical limits.** Exact citations and2modalities prevent fabricated references, but do not settle causality. Alternatives/uncertainty and human review remain visible. Repair templates are concrete, scoped and nonexecutable.
- **No repair actuator.** The required outcome is an evidence-backed proposal requiring approval. A separate human-approved implementation would be new work; a model-generated `approved:true` field has no authority. Experiment cleanup only restores its own injected control.
- **One approved route, bounded calls.** Same host cookllm connection as preceding AI projects, no tools/new model/billing route. Reservation-before-publication and host attempt ledger accept an interrupted attempt rather than risk duplicate spending. Dollar cost remains unavailable.

Observed corrections before model evaluation: worker's lifespan test created different context-manager instances, so root replaced it with a real async-with lifecycle and tested source/cache corruption separately. SQLite connections now close explicitly. Root reviewer reproduced interrupted-control recovery, duplicate-trace acceptance, discarded failed-output token usage, pre-bound recursive canary scan and misleading healthy cache status; all received focused regressions. Relative-latency baseline initially parsed sentence-final punctuation as part of a float; two failed analyses remain in the journal and corrected runs use the same immutable evidence. Baseline now requires an actual relative delta plus a slow aggregate span, not mere presence of duration fields. No model-output-driven prompt tuning or claim of unseen fault-family evaluation.

Later findings/results belong in VERIFICATION.md, including cold-start timing confounds and model failures. No benchmark numbers are invented or selected from retries.
